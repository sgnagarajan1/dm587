Main readings

  • ACME Labs — Python Essentials

    Programming reference. Lab 1: Intro to Python; Lab 2: The Standard Library; Lab 3: Object-oriented Programming; Lab 4: Intro to NumPy. The lecture table links to the assigned sections.

  • Stephen Boyd and Lieven Vandenberghe — Introduction to Applied Linear Algebra: Vectors, Matrices, and Least Squares

    Cambridge University Press, 2018. Linear algebra reference for the course; the full text is freely available on the authors’ website.

  • Lab numbers follow the Python Essentials booklet; the online links use section headings.

Supplementary readings will be added as the course progresses.
